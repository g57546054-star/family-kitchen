## 可重复执行的检查

从仓库根目录安装两套锁定依赖后：

```bash
npm run check --prefix miniprogram
npm test --prefix miniprogram
npm test --prefix cloudfunctions/family
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:layout --prefix miniprogram
npm run build
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm test
```

## 明确未验证

当前 Linux 云环境没有微信开发者工具、官方 WXML/WXSS 编译器、GUI、合法生产 AppID、微信真机或上传凭证，因此以下步骤**未执行**：

1. 微信开发者工具实际导入、官方“构建 npm”及官方编译。
2. TDesign 在微信基础库中的实际渲染、字体、弹层、键盘遮挡、安全区和滚动表现，以及官方 npm 构建后的首包体积/代码依赖裁剪结果。
3. 游客模式/测试号与真实 AppID 的能力差异。
4. 真机聊天文件选择、文件传输助手读取、`wx.shareFileMessage` 发送、剪贴板权限及取消发送行为。
5. iOS/Android 微信中的关闭重开、真实存储容量、恢复备份的实机端到端验收。
6. 任何 CloudBase、鉴权、家庭共享同步或冲突解决。提供者明确禁用。
7. 微信小程序二维码生成、真机预览、上传、提审、上线、域名配置或云环境创建。本阶段不执行这些操作。

`project.config.json` 的游客占位 AppID 便于导入源码，不代表已注册、发布了真实小程序。后续应按 `miniprogram/README.md` 的验收清单在开发者工具与真机完成验证。
